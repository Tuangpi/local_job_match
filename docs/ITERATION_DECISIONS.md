# Phase 6 - Evidence-Led Iteration Decisions

Based on the completed pilot-readiness work, the following decisions are recorded:

- Project milestones remain deferred. The `project_milestones` schema is available if pilot users request milestone tracking for larger projects.
- No monetization model is enabled during the pilot. Commission, paid qualified leads, and expert subscriptions remain deferred until pilot usage data is reviewed.
- Messaging integrations remain deferred pending access, permission, and notification requirements.
- Township/category filtering is sufficient for the initial launch; geospatial matching is not added.
- Payment integration remains deferred pending legal, provider, and operational review. Direct settlement continues during the pilot.

These decisions keep the MVP focused and avoid premature complexity.
